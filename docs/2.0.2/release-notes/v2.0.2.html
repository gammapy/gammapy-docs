2.0.2 (27th November, 2026)#

  • Released 27th November, 2026

  • contributors: 27

  • 126 pull requests since v2.0.1 (not all listed below)

  • 18 closed issues

Summary#

A security vulnerability was found (CVE-2026-134694). When reading a WCS map from a FITS file (e.g. with gammapy.maps.Map.read), Gammapy (<=2.1) evaluates the content of the WCSSHAPE GADF header keyword as Python code. A maliciously crafted FITS file could therefore execute arbitrary code as user on your computer when opened. All Gammapy versions up to 2.0.1 and 2.1 are affected. This has been adjusted in this version. We thank Dilanka Kaushal Hewage (@r3vpwnx) for reporting the issue.

Documentation improvements#

  • Remove unused obstime and location variables from FoVICRSFrame docstring example. [#6460]

  • Fix issue in Fermi-LAT tutorial where dimmest sources are used for fitting rather than brightest. [#6750]

Bug Fixes#

  • Ignore observations without spatial overlap with the target dataset geometry in DatasetsMaker instead of raising an error. [#6194]

  • Adapted SpectrumDataset.create() to avoid creating PSFMap during dataset creation. Moved creation of SpectrumDataset.create() into the SpectrumDataset class. Added check for RegionGeom of given geometry. [#6259]

  • Fixed kinematics in gammapy.astro.darkmatter.DarkMatterDecaySpectralModel. The model now correctly uses mass/2 for the primary flux lookup. [#6298]

  • Correct issue #6304. Include CITATION file in the gammapy directory. Modify the _get_bibtex and _get_acknowledgement functions accordingly. [#6308]

  • Add default Parameter values on init in gammapy.astro models. This solves docs build issues which appeared recently. [#6333]

  • Correct bug with command-line-interface (gammapy analysis run) that forces background maker method to be reflected regions. [#6367]

  • Fix an off-by-one error in pix_to_idx by clipping indices to npix - 1. [#6383]

  • Fix hpx.geom.pix_to_idx to correctly handle non-spatial pixel coordinates, ensuring consistency with WCS. [#6388]

  • requests and tqdm are now included as core dependencies so that gammapy download datasets works out of the box without requiring users to install extra packages manually. [#6400]

  • Parameter bounds are now synchronized dynamically with UniformPrior and LogUniformPrior bounds to prevent Minuit from hitting infinite likelihood. [#6409]

  • Fix gammapy.datasets.utils.set_and_restore_mask_fit such as it does not ignore the existing dataset.mask_fit by default. [#6416]

  • Fix a RuntimeWarning due to division by zero in plot_offset_dependence when the maximum effective area is zero. [#6450]

  • Fix flux estimates in gammapy.estimators.TSMapEstimator (now the kernel is properly normalized in each energy bin rather than over the total energy range). [#6466]

  • Fix select_time in EventList, GTI and Observation to always utilise start time (inclusive) and stop time (exclusive). [#6497]

  • Fix unit handling in RegionNDMap.plot_mask [#6520]

  • Propagated the overwrite argument in the write method of TemplateNDSpectralModel. [#6525]

  • Introduce default threshold value to remove numerical artifacts created when applying to_edisp_kernel(). [#6547]

  • Correct gammapy.datasets.FluxPointsDataset.plot_residuals() x-axis unit, remove ax_spectrum and ax_residuals parameter in gammapy.datasets.FluxPointsDataset.plot_fit() and adjust documentation. [#6615]

  • stack(other) now skips stacking if other mask_safe is invalid. This prevents stacking gti of invalid dataset. [#6621]

  • Fixes integrate_spectrum to allow integration of spectral models without a closed analytical form (e.g. BrokenPowerLawSpectralModel) with energy bounds given as arrays of length 1. [#6622]

  • Fixes bug to return ax object for TemplateSpatialModel.plot(). [#6636]

  • Fixes a bug in the EnergyDependentMorphologyEstimator to allow for multiple datasets to be handled correctly. [#6640]

  • Corrects make_effective_livetime_map to use observation pointing to compute livetime map. [#6643]

  • Fixes plot_offset_dependence() to remove area being divided twice. [#6666]

  • Fix default behavior of sum_over_energy_groups=False case in gammapy.estimators.ExcessMapEstimator. [#6685]

  • Remove dependency to regions deprecated function pixel_scale_angle_at_skycoord in SkyPolygonRegion. [#6705]

  • Add configuration of interpolation options for LightCurveTemplateTemporalModel, now default is to return zero when evaluating outside the times in the template. [#6712]

  • Fixes compute_differential_jfactor to use the physical impact parameter in the line-of-sight integration and avoid evaluating the integrable closest-approach singularity directly. [#6757]

  • Fix Asimov dataset computation for MapDatasetOnOff: use alpha * N_OFF as expected background. [#6762]

  • Fix parsing of the scale parameter when read from a dictionary in TemplatePhaseCurveTemporalModel. [#6807]

  • Fix broadcasting in integral [#6813]

  • Makes sure FoV offsets in _get_fov_coord are calculated in the correct coordinate frame. [#6861]

  • Fix nan in sensitivity computation using Asimov dataset. [#6862]

  • Fixes an out-of-memory error when computing the covariance of models with a large number of parameters (e.g. a full source catalogue) by building diagonal covariances lazily in gammapy.modeling.covariance.Covariance. [#6867]

  • Fixes containment when rad is larger than the last bin of the PSF rad axis. [#6887]

  • Recompute upper limits using likelihood profiles if the default method using fit condidence fails in gammapy.estimators.ParameterEstimator. [#6900]

  • Fixes error in getting the pivot_energy for a CompoundSpectralModel or model which does not contain a reference. [#6916]

  • Fix to_dict() of TemplateSpectralModel, PiecewiseNormSpectralModel, EBLAbsorptionNormSpectralModel and PiecewiseNormSpatialModel failing on big-endian arrays. [#6952]

  • Fix the normalisation of compute_fpp to match Edelson et al. (2002), also when the light curve has NaN values. [#7014]

  • Correct location of HEGRA array in ~gammapy.utils.observers.py [#7068]

  • Modify handling of GADF keyword WCSSHAPE in WcsGeom to validate its content. [#7087]

  • Default energy was a single Quantity instead of a list of Quantity, causing Background2D.plot_at_energy() and Background3D.plot_at_energy() to fail when using the default. [#7101]
