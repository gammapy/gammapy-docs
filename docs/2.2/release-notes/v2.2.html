2.2 (27th November, 2026)#

  • Released: 27th November, 2026

  • New contributors: 7 (Marked with * in the list)

  • Total contributors: 30

  • Total merged PRs: 200

Summary#

Gammapy v2.2 is a new feature release with a number of performance improvements, new features and bug fixes. The main themes include new tools for Bayesian inference, a broad overhaul of the dark matter module, and ASDF serialization of the core data structures.

Python 3.14 and 3.15 are now supported, and issues encountered with regions in the previous versions are now resolved. Three new notebooks have been added and the CTAO notebook significantly updated.

A security vulnerability was found (CVE-2026-134694). When reading a WCS map from a FITS file (e.g. with gammapy.maps.Map.read), Gammapy (<=2.1) evaluates the content of the WCSSHAPE GADF header keyword as Python code. A maliciously crafted FITS file could therefore execute arbitrary code as user on your computer when opened. All Gammapy versions up to 2.1 are affected. This has been adjusted in this version. We thank Dilanka Kaushal Hewage (@r3vpwnx) for reporting the issue.

Dark matter module#

The dark matter module has been substantially refactored and extended in this release. The spectral model classes have been unified into a single class handling both annihilation and decay, with improved parameter validation and an overall cleaner code structure. CosmiXs is now the default source for dark matter spectra, replacing PPPC4DMID; note that this changes the results of analyses that relied on the previous default. Users can also provide their own custom spectra from a file.

The computation of astrophysical factors has been improved, with corrections for extragalactic sources, the line-of-sight geometry and the treatment of the central pixel. Notably, uncertainties on the astrophysical factor can now be included as a nuisance parameter profiled in the likelihood fit, so that limits on the annihilation cross-section or decay lifetime account for the uncertainty on the target’s dark matter distribution, yielding more realistic and typically more conservative constraints. The documentation and tutorials have been updated accordingly, with new and improved tutorials covering both a basic introduction and a complete analysis.

ASDF serialization#

Maps, geometries (WCS, HEALPix, region), map axes, GTIs, IRF maps, Datasets and Models can now be written to and read from ASDF. This is the groundwork for storing a complete analysis state in a single, self-describing file, and is a part of an overhaul of the I/O code in Gammapy. An associated entry in the HowTo is added as an explanation for ASDF serialisation.

Estimators and flux upper limits#

Significant additions have been made to our estimator package. Previously, hidden failures sometimes used to occur at low statistics, causing very low upper limits. This has now been corrected. If a failure is detected during the fit for upper limit computation, the method internally switches to upper limit computation using likelihood profiles. The upper limit tutorial has been updated with more information.

A preliminary implementation of a new RegularizedFluxPointsEstimator is introduced for flux point computation in true-energy space with a given regularisation, and will be documented in future releases.

Other#

The 4FGL catalog is updated, with support for the FL16Y list. A new OnOffBackgroundMaker with an associated tutorial is provided for background estimation with paired off runs. The nautilus is now available as a Sampler backend, which is better suited for higher dimensionality problems, and LogNormalPrior and SamplesKDEPrior are introduced. A new tutorial is added explaining the details of Bayesian model selection.

API changes#

  • The constructor of ObservationTable now takes an argument table instead of data. [#6620]

  • Deprecated make_map_exposure_true_energy, use the make_exposure method on MapDatasetMaker instead. [#6882]

  • Deprecate gammapy.makers.utils.make_psf_map. [#6893]

  • The options of Sampler are now given in a single options dictionary, using the backend’s own option names. [#6898]

  • Deprecate gammapy.makers.utils.make_edisp_map and gammapy.makers.utils.make_edisp_kernel_map. [#6906]

  • Deprecate gammapy.makers.utils.make_map_background_irf. [#6946]

  • Fix the gammapy-dev conda environment for compiling sherpa from source and adding all documentation dependencies. [#6930]

New features#

  • Add CirclePixelRegionArray and CircleSkyRegionArray classes to support array valued regions. [#5420]

  • Add RegularizedFluxPointsEstimator to perform estimate of flux points in true energy space using a regularized likelihood approach. [#5625]

  • Add plot_pulse_profile_3PC function to plot pulse profiles from the Fermi-LAT 3PC catalog. [#5761]

  • Add utility function to creates a 2D grid of RectangleSkyRegion tiles on a given WCS. [#6006]

  • Add SamplesKDEPrior class to create a prior from samples using scipy.stats.gaussian_kde. [#6503]

  • Add nautilus-sampler as a possible Sampler backend. [#6596]

  • Update Fermi-LAT 4FGL catalog and add support for FL16Y list in SourceCatalog4FGL. [#6617]

  • Add support for creating a DataStore from the results of a ivoa TapQuery. [#6653]

  • Implementation of the option of using custom files as dark matter spectra sources. [#6660]

  • Add ASDF serialization support for MapAxis. [#6706]

  • Add ASDF serialization support for TimeMapAxis and LabelMapAxis . [#6722]

  • Add ASDF serialization support for MapAxes. [#6735]

  • Add downsample functionality for the energy_true axis, fix downsample behaviour, and restrict the axes for downsampling. [#6740]

  • Added add_factor_prior helper function to support log-normal nuisance parameter treatment for astrophysical J-factors and D-factors. [#6741]

  • Fixed JFactory to correctly compute J/D-factors for extragalactic sources by decoupling rmax from distance and propagating the source distance through the line-of-sight integration geometry. [#6743]

  • Implementation of parameter validation and code restructuring for Dark Matter spectral models. [#6744]

  • Add ASDF serialization support for WcsGeom. [#6751]

  • Add ASDF serialization support for HpxGeom. [#6761]

  • Add ASDF serialization support for RegionGeom. [#6771]

  • Add a dark matter analysis tutorial covering the basics of J/D-factor computation, spectral models, and expected gamma-ray flux. [#6782]

  • Add ASDF serialization support for WcsNDMap. [#6790]

  • Add ASDF serialization support for HpxNDMap. [#6791]

  • Add ASDF serialization support for RegionNDMap. [#6794]

  • Addition of LogNormalPrior class. [#6799]

  • Ensure TimeMapAxis start and stop values are exported to table in isot format. [#6805]

  • Deprecate stat_sum and make stat_sum_likelihood and stat_sum_likelihood public. [#6812]

  • Add OnOffBackgroundMaker for on-off analysis. [#6824]

  • Creation of class DarkMatterSpectralModel as the unification of DarkMatterAnnihilationSpectralModel and DarkMatterDecaySpectralModel. The new class has a parameter annihilation to set the type of dark matter process. [#6825]

  • Add ASDF serialization support for Maps. [#6830]

  • Add ASDF serialization support for GTI. [#6831]

  • Add ASDF serialization support for PSFMap, RecoPSFMap, EDispMap, EDispKernelMap. [#6833]

  • Add Fourth Fermi-LAT Catalog of High-Energy Sources (4FHL). Older 2FHL catalog has been deprecated as of next release (v2.2). [#6838]

  • Add BasePlotter class, first building plot for the new Plotters API defined in PIG 31. [#6845]

  • Add ASDF serialization support for MapDataset and MapDatasetOnOff. [#6849]

  • Add ASDF serialization support for Models. [#6850]

  • Adapt the default spectra source in DarkMatterSpectralModel and ContinuumPrimaryFlux from PPPC4DMID to CosmiXs. [#6885]

  • Add Eemin, Eemax (for leptonic models) or Epmin, Epmax (for hadronic models) as fit parameters in the NaimaSpectralModel. [#6889]

  • Remove the limit of 5 non-spatial axes when reading a RegionNDMap with gadf format. [#6949]

  • Fixes integrate_spectrum to allow integration of spectral models without a closed analytical form (e.g. BrokenPowerLawSpectralModel) with energy bounds given as arrays of length 1. [#6622]

  • Fixes bug to return ax object for TemplateSpatialModel.plot(). [#6636]

  • Fixes a bug in the EnergyDependentMorphologyEstimator to allow for multiple datasets to be handled correctly. [#6640]

  • Corrects make_effective_livetime_map to use observation pointing to compute livetime map. [#6643]

  • Fixes plot_offset_dependence() to remove area being divided twice. [#6666]

  • Fix default behavior of sum_over_energy_groups=False case in gammapy.estimators.ExcessMapEstimator. [#6685]

  • Remove dependency to regions deprecated function pixel_scale_angle_at_skycoord in SkyPolygonRegion. [#6705]

  • Add configuration of interpolation options for LightCurveTemplateTemporalModel, now default is to return zero when evaluating outside the times in the template. [#6712]

  • Fixes incorrect calling of dataset for frozen models in FluxCollectionEstimator. [#6721]

  • Add unit support to the violins plot from plot_samples_violin_vs_energy used with the FluxCollectionEstimator [#6756]

  • Fixes compute_differential_jfactor to use the physical impact parameter in the line-of-sight integration and avoid evaluating the integrable closest-approach singularity directly. [#6757]

  • Fix Asimov dataset computation for MapDatasetOnOff: use alpha * N_OFF as expected background. [#6762]

  • Fix the FluxCollectionEstimator to support computation over datasets with different spatial geometries, and single flux point. [#6785]

  • Fix RegionGeom ASDF roundtrip for DS9-formatted regions to clear meta and visual on write. [#6801]

  • Fix parsing of the scale parameter when read from a dictionary in TemplatePhaseCurveTemporalModel. [#6807]

  • Fix broadcasting in integral [#6813]

  • Fixes the line-of-sight integration geometry in JFactory to account for observers inside or outside the radial integration region. [#6819]

  • Fixes JFactory when a map pixel center coincides exactly with the dark-matter halo center. [#6828]

  • format_plot_xaxis no longer produces overlapping scientific-notation minor tick labels on a log x-axis spanning less than one decade. [#6847]

  • Makes sure FoV offsets in _get_fov_coord are calculated in the correct coordinate frame. [#6861]

  • Fix nan in sensitivity computation using Asimov dataset. [#6862]

  • Add gammapy.stats.utils.ts_to_sigma_sensitivity and gammapy.stats.utils.sigma_to_ts_sensitivity as separate functions and fix computation with more than one degree of freedom [#6864]

  • Fixes an out-of-memory error when computing the covariance of models with a large number of parameters (e.g. a full source catalogue) by building diagonal covariances lazily in Covariance. [#6867]

  • Fixes e_peak value for the case where the energy scale E_s is different from the reference energy E_0. [#6884]

  • Fixes containment when rad is larger than the last bin of the PSF rad axis. [#6887]

  • Recompute upper limits using likelihood profiles if the default method using fit confidence fails in ParameterEstimator. [#6900]

  • Fixes error in getting the pivot_energy for a CompoundSpectralModel or model which does not contain a reference. [#6916]

  • Fix error in gammapy.data.ivoa.make_hdu_table. [#6920]

  • Fix to_dict() of TemplateSpectralModel, PiecewiseNormSpectralModel, EBLAbsorptionNormSpectralModel and PiecewiseNormSpatialModel failing on big-endian arrays. [#6952]

  • Fix the normalisation of compute_fpp to match Edelson et al. (2002), also when the light curve has NaN values. [#7014]

  • Correct location of HEGRA array in ~gammapy.utils.observers.py [#7068]

  • Modify handling of GADF keyword WCSSHAPE in WcsGeom to validate its content. [#7087]

  • Default energy was a single Quantity instead of a list of Quantity, causing Background2D.plot_at_energy() and Background3D.plot_at_energy() to fail when using the default. [#7101]
